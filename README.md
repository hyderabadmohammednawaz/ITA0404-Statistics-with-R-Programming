# 📖 Unit-wise Learning

### Unit I - Introduction to R Programming

Variables, data types, vectors, lists, matrices, arrays, factors, data frames, functions and classes.

### Unit II - Looping, Control Structures, Functions & Recursion

`for` and `while` loops, `if-else`, operators, functions, return values and recursion.

### Unit III - Data Frames & File Operations

Data frames, data reshaping, melting, casting, merging and reading/writing files.

### Unit IV - Exploratory Data Analysis

Mean, median, mode, range, quartiles, variance, standard deviation, skewness, kurtosis, covariance and correlation.

### Unit V - Plotting & Regression Analysis

Box plots, bar plots, pie charts, histograms, line charts, scatter plots, ggplot2, distributions, simple regression, multiple regression, logistic regression and Poisson regression.
